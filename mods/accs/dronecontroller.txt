# 드론 컨트롤러 — 등에 멘 드론 도킹 배낭과 양 손목의 조종 단말. 전기 드론을 날려 멀리서 상대를 감전시키는 데 강하고, 맞붙는 힘은 약하다.
# tech X      드론 쇼크 블로우  — 블로우를 꽂으며 드론의 전기를 흘려 상대를 감전시키는 기술입니다.
# tech D+C    드론 어깨치기    — 달려가며 전기를 두른 어깨로 들이받아 상대를 감전시키는 기술입니다.
# tech D+X    드론 대시 킥     — 달려가며 스파크를 뿜는 발차기로 상대를 날리는 기술입니다.
# tech V+X    드론 낙하 킥     — 공중에서 전기를 두른 발로 내려찍어 상대를 감전시키는 기술입니다.
# tech Z+C    드론 출격       — 소형 정찰 드론 한 기를 직선으로 날려 상대를 쫓아가 착탄 지점에 전기 폭발을 일으키는 원거리 기술입니다.
# tech Z+X    드론 더블 출격   — 폭격 드론 두 기를 양옆으로 시간차를 두고 날려 상대를 쫓아가 전기 폭발을 일으키는 원거리 기술입니다.
# tech Z+XC   드론 일제 사격   — 폭격 드론 다섯 기를 넓은 부채꼴로 일제히 출격시켜 상대를 쫓아가 연달아 감전시키는 지상 필살기입니다.
# tech V+XC   드론 공중 투하   — 높이 뛰어올라 대형 폭격 드론 세 기를 위에서 투하해 상대를 쫓아가 감전시키는 점프 필살기입니다.
# tech D+XC   드론 돌격 러시   — 드론을 앞세워 돌진하며 폭격 드론 세 기를 연달아 출격시켜 상대를 쫓아가 감전시키는 대시 필살기입니다.
